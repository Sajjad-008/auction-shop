# فهرست کارهای بک‌اند (اوج‌بها)

مرجع قرارداد داده: `client/src/types.ts`. پاسخ API باید با این نوع‌ها هم‌خوان باشد؛ هر تغییر با هماهنگی فرانت.

قراردادهای عمومی: زمان‌ها ISO UTC، مبلغ‌ها عدد صحیح (تومان)، پیام‌های خطا فارسی و رسمی، قالب خطا `{ "message": "..." }`.

## فناوری پیشنهادی (قابل بحث)

Node.js + Express + TypeScript، SQLite با `better-sqlite3`، اعتبارسنجی با `zod`، رمز با `bcrypt`، نشست با JWT در کوکی `httpOnly`، آپلود با `multer`، امنیت با `helmet` و `express-rate-limit`، CORS فقط برای `http://localhost:5173`.

## قوانین کسب‌وکار (فقط سمت سرور معتبرند)

**ثبت پیشنهاد** باید داخل یک تراکنش (`BEGIN IMMEDIATE`) انجام شود تا دو پیشنهاد هم‌زمان قیمت را خراب نکنند:

1. کاربر وارد نشده باشد ← 401
2. نقش کاربر فروشنده باشد ← 403
3. مزایده وجود نداشته باشد ← 404
4. زمان فعلی بعد از `end_at` باشد ← 409
5. آخرین پیشنهاد مال همین کاربر باشد ← 409
6. مبلغ کمتر از (بالاترین پیشنهاد + گام) یا (قیمت پایه برای پیشنهاد اول) باشد ← 422
7. در غیر این صورت: ثبت پیشنهاد و ساخت اعلان «پیشنهاد بالاتر» برای نفر قبلی

**ساخت مزایده** (فقط فروشنده): عنوان ≥ ۵ حرف، توضیحات ≥ ۲۰ حرف، قیمت پایه ≥ ۱۰۰٬۰۰۰، گام ≥ ۱۰٬۰۰۰ و ≤ قیمت پایه، مدت از بین ۱۰ دقیقه، ۱ ساعت، ۶ ساعت، ۱ روز، ۳ روز و ۷ روز.

**حذف مزایده**: فقط صاحب آن و فقط اگر هیچ پیشنهادی ندارد.

**نام کاربر در تاریخچه‌ی پیشنهادها** باید نیمه‌پنهان برگردد (مثلاً `ع***ی`) و فیلد `mine: true` مشخص کند پیشنهاد مال کاربر جاری است. فرانت الان به‌جای این از نام ثابت «من» استفاده می‌کند.

**نقش کاربر** را هرگز از بدنه‌ی درخواست نپذیرید؛ بعد از ثبت‌نام در پایگاه‌داده ذخیره و از توکن خوانده شود.

## API

| روش و مسیر                                                               | کار                                                                                       | دسترسی         |
| ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- | -------------- |
| `POST /api/auth/register`                                                | ثبت‌نام (نام، ایمیل، رمز، نقش `buyer` یا `seller`)                                        | همه            |
| `POST /api/auth/login`                                                   | ورود                                                                                      | همه            |
| `POST /api/auth/logout`                                                  | خروج                                                                                      | کاربر          |
| `GET /api/auth/me`                                                       | کاربر جاری                                                                                | کاربر          |
| `GET /api/auctions?category=&q=&status=&sort=`                           | لیست با فیلتر و جستجوی متنی (عنوان و توضیحات)                                             | همه            |
| `GET /api/auctions/:id`                                                  | جزئیات با تاریخچه‌ی پیشنهادها                                                             | همه            |
| `POST /api/auctions/:id/bids`                                            | ثبت پیشنهاد                                                                               | خریدار         |
| `POST /api/auctions`                                                     | ساخت مزایده (با آپلود عکس)                                                                | فروشنده        |
| `DELETE /api/auctions/:id`                                               | حذف مزایده                                                                                | فروشنده (مالک) |
| `GET /api/seller/auctions`                                               | مزایده‌های فروشنده                                                                        | فروشنده        |
| `GET /api/me/bids`                                                       | مزایده‌هایی که کاربر در آن‌ها پیشنهاد داده، با وضعیت (`leading`، `outbid`، `won`، `lost`) | خریدار         |
| `GET/POST/DELETE /api/favorites`                                         | علاقه‌مندی‌ها                                                                             | خریدار         |
| `GET /api/notifications`                                                 | لیست اعلان‌ها                                                                             | کاربر          |
| `PATCH /api/notifications/:id/read` و `POST /api/notifications/read-all` | خوانده‌شدن                                                                                | کاربر          |
| `DELETE /api/notifications/:id`                                          | حذف                                                                                       | کاربر          |
| `GET/POST /api/tickets`                                                  | لیست و ساخت تیکت (دسته، عنوان، متن، ≤ ۲ عکس)                                              | کاربر          |
| `GET /api/tickets/:number`                                               | گفتگو (فقط تیکت خود کاربر)                                                                | کاربر          |
| `POST /api/tickets/:number/messages`                                     | پیام جدید                                                                                 | کاربر          |
| `PATCH /api/tickets/:number/status`                                      | بستن و بازگشایی                                                                           | کاربر          |
| `POST /api/admin/tickets/:number/reply`                                  | پاسخ پشتیبانی                                                                             | ادمین          |

فرانت الان پاسخ خودکار نمونه می‌سازد. با آمدن بک‌اند، آن را حذف می‌کنیم و فقط پاسخ ادمین نمایش داده می‌شود.

## آپلود تصویر

فقط `image/jpeg`، `image/png` و `image/webp`، حداکثر ۱ مگابایت، نام فایل تصادفی (نه نام اصلی)، سرو از مسیر `/uploads`. نوع فایل را از محتوا بررسی کنید، نه فقط از پسوند.

## کارهای زمان‌دار

- بعد از `end_at`: برنده مشخص شود و اعلان «برنده شدید» برای او ساخته شود.
- یک ساعت مانده به پایان: اعلان «در آستانه‌ی پایان» برای کسانی که پیشنهاد داده‌اند.
- پیاده‌سازی ساده: یک `setInterval` هر دقیقه که مزایده‌های تازه‌تمام‌شده را بررسی کند.

## به‌روزرسانی لحظه‌ای

- مرحله‌ی ۱: فرانت هر ۵ ثانیه `GET /api/auctions/:id` را می‌خواند (Polling).
- مرحله‌ی ۲ (اختیاری): Server-Sent Events روی `/api/auctions/:id/stream`.

## امنیت

- هش رمز با `bcrypt`، هرگز رمز یا هش در پاسخ نیاید.
- محدودیت تعداد درخواست برای ورود و ثبت‌نام.
- کوکی `httpOnly` و `sameSite`.
- همه‌ی ورودی‌ها با `zod` اعتبارسنجی شوند.
- کاربر فقط به داده‌ی خودش (تیکت، اعلان، علاقه‌مندی) دسترسی داشته باشد.

## نقاط اتصال فرانت

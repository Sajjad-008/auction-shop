# مزایده‌گاه

وب‌سایت مزایده آنلاین؛ پروژه‌ی درس طراحی واسط کاربری.

کاربر می‌تواند مزایده‌ها را ببیند، بر اساس دسته‌بندی فیلتر کند، در مزایده‌ی فعال پیشنهاد ثبت کند و وضعیت پیشنهادهایش را پیگیری کند.

## وضعیت پروژه

| بخش                       | وضعیت        |
| ------------------------- | ------------ |
| طراحی رابط (Figma)        | انجام شد     |
| فرانت‌اند (React)         | در حال توسعه |
| بک‌اند (Express و SQLite) | شروع نشده    |

> فعلاً داده‌ها ثابت هستند و بعد از رفرش صفحه به حالت اول برمی‌گردند. ورود و ثبت‌نام هم فقط در سمت مرورگر شبیه‌سازی شده‌اند. با آمدن بک‌اند، هر دو واقعی می‌شوند.

## قابلیت‌ها

- لیست مزایده‌ها با تایمر معکوس زنده (قرمز شدن در ۵ دقیقه‌ی آخر)
- سایدبار برای جابه‌جایی بین بخش‌ها و دسته‌بندی‌ها
- صفحه‌ی جزئیات مزایده با تاریخچه‌ی پیشنهادها
- فرم ثبت پیشنهاد با اعتبارسنجی (حداقل گام، مرحله‌ی تأیید قبل از ثبت)
- صفحه‌ی «پیشنهادهای من» با تب‌های وضعیت (در صدر، پیشی گرفته شده، برنده شدم)
- ورود و ثبت‌نام با اعتبارسنجی فرم
- تم تاریک و روشن
- راست‌چین و فارسی (فونت وزیرمتن)
- واکنش‌گرا (موبایل و دسکتاپ)

## فناوری‌ها

- React و Vite
- Tailwind CSS
- React Router
- Lucide React (آیکون‌ها)

## اجرای پروژه

نیازمند Node.js است.

```bash
git clone https://github.com/Sajjad-008/auction-shop.git
cd auction-shop/client
npm install
npm run dev
```

سپس آدرس `http://localhost:5173` را باز کنید.

## ساختار پوشه‌ها

```
auction-shop/
└── client/
    ├── public/images/     عکس مزایده‌ها
    ├── scripts/           اسکریپت کم‌حجم کردن عکس‌ها
    └── src/
        ├── components/    کامپوننت‌ها (کارت، تایمر، سایدبار، ...)
        ├── pages/         صفحه‌ها (لیست، جزئیات، پیشنهادهای من، ورود)
        ├── data/          داده‌ی آزمایشی
        ├── hooks/         هوک‌ها (تم)
        └── utils/         توابع کمکی و اعتبارسنجی
```

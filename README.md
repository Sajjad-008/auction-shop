# مزایده‌گاه

وب‌سایت مزایده‌ی آنلاین؛ پروژه‌ی درس طراحی واسط کاربری.

خریدار می‌تواند مزایده‌ها را ببیند، جستجو و فیلتر کند، پیشنهاد ثبت کند و وضعیت پیشنهادهایش را دنبال کند. فروشنده پنل جدا دارد و می‌تواند مزایده بسازد و مدیریت کند. هر دو نقش اعلان و پشتیبانی تیکتی دارند.

## وضعیت پروژه

| بخش                            | وضعیت                   |
| ------------------------------ | ----------------------- |
| طراحی رابط (Figma)             | انجام شد (نسخه‌ی اولیه) |
| فرانت‌اند (React و TypeScript) | انجام شد                |
| بک‌اند (Express و SQLite)      | شروع نشده               |

> **توجه:** فعلاً پروژه فقط در مرورگر کار می‌کند و سروری وجود ندارد.
>
> - مزایده‌ها و پیشنهادهای نمونه ثابت هستند؛ مزایده‌های ساخته‌شده توسط فروشنده در `localStorage` می‌مانند.
> - ورود، ثبت‌نام و **نقش کاربر (خریدار یا فروشنده)** شبیه‌سازی شده‌اند و امنیت واقعی ندارند. رمز عبور بررسی و ذخیره نمی‌شود.
> - همه‌ی پیشنهادهای خریدار با نام «من» ثبت می‌شوند و اعلان‌ها بین حساب‌های یک مرورگر مشترک هستند.
> - **پاسخ پشتیبانی خودکار و نمونه است** و انسان آن را نمی‌نویسد.
> - اسم شرکت‌های بخش «همکاران ما» در صفحه‌ی اصلی **خیالی** هستند و فقط برای نمایش در پروژه‌ی دانشگاهی گذاشته شده‌اند.
> - پرداخت آنلاین وجود ندارد.
>
> با آمدن بک‌اند، همه‌ی این بخش‌ها واقعی می‌شوند.

## قابلیت‌ها

### همه‌ی کاربران (حتی مهمان)

- صفحه‌ی معرفی با راهنمای کار، آمار متحرک، همکاران، بخش فروشنده‌ها و سؤالات متداول
- لیست مزایده‌ها با تایمر معکوس زنده (قرمز شدن در ۵ دقیقه‌ی آخر)
- صفحه‌ی «مزایده‌های فعال» با فیلتر (به‌زودی تموم می‌شه، رقابتی، بازه قیمت) و مرتب‌سازی جدا
- جستجوی متنی با امکان انتخاب دسته‌بندی
- صفحه‌ی جزئیات مزایده با تاریخچه‌ی پیشنهادها

### خریدار

- ثبت پیشنهاد با اعتبارسنجی (حداقل گام) و مرحله‌ی تأیید قبل از ثبت
- «پیشنهادهای من» با تب‌های وضعیت (در صدر، پیشی گرفته شده، برنده شدم)
- علاقه‌مندی‌ها (قلب روی کارت و صفحه‌ی جزئیات)

### فروشنده

- پنل جدا با سایدبار اختصاصی
- داشبورد با آمار مزایده‌ها
- ساخت مزایده (عنوان، دسته، توضیحات، قیمت پایه، گام پیشنهاد، مدت، عکس) با پیش‌نمایش زنده‌ی کارت
- «مزایده‌های من» با تب‌های وضعیت و حذف مزایده (فقط اگر پیشنهادی نداشته باشد)

### مشترک

- اعلان‌ها: زنگوله با نشان خوانده‌نشده و صفحه‌ی کامل اعلان‌ها
- پشتیبانی: ثبت تیکت با دسته‌بندی و پیوست عکس، گفتگو و بستن تیکت
- ورود و ثبت‌نام با اعتبارسنجی فرم و انتخاب نوع حساب
- بازگشت به همان صفحه‌ی قبلی بعد از ورود
- تم تاریک و روشن
- راست‌چین و فارسی (فونت وزیرمتن)
- واکنش‌گرا (موبایل و دسکتاپ)

## فناوری‌ها

- React و TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React (آیکون‌ها)

## اجرای پروژه

نیازمند Node.js است.

```bash
git clone https://github.com/Sajjad-008/auction-shop.git
cd auction-shop/client
npm install
npm run dev
```

سپس آدرس `http://localhost:5173` را باز کنید.

### دستورها

| دستور               | کار                        |
| ------------------- | -------------------------- |
| `npm run dev`       | اجرای سرور توسعه           |
| `npm run typecheck` | بررسی نوع‌ها (TypeScript)  |
| `npm run build`     | ساخت نسخه‌ی نهایی          |
| `npm run preview`   | پیش‌نمایش نسخه‌ی ساخته‌شده |

### امتحان نقش‌ها

چون ورود شبیه‌سازی شده، برای دیدن هر پنل کافی است:

1. با «ثبت‌نام» یک حساب **خریدار** و یک حساب **فروشنده** (با دو ایمیل متفاوت) بسازید.
2. با هر ایمیل وارد شوید تا پنل همان نقش باز شود. ایمیلی که قبلاً ثبت‌نام نشده باشد، خریدار حساب می‌شود.

## مسیرها

| آدرس                                         | صفحه                      | دسترسی                   |
| -------------------------------------------- | ------------------------- | ------------------------ |
| `/`                                          | صفحه‌ی معرفی              | همه                      |
| `/auctions`، `/active`، `/category/:key`     | لیست مزایده‌ها            | همه                      |
| `/auction/:id`                               | جزئیات مزایده             | همه (پیشنهاد فقط خریدار) |
| `/search`                                    | نتایج جستجو               | همه                      |
| `/login`، `/signup`                          | ورود و ثبت‌نام            | مهمان                    |
| `/my-bids`، `/favorites`                     | پیشنهادها و علاقه‌مندی‌ها | خریدار                   |
| `/notifications`، `/support`                 | اعلان‌ها و پشتیبانی       | کاربر واردشده            |
| `/seller`، `/seller/auctions`، `/seller/new` | پنل فروشنده               | فروشنده                  |

## روش کار با گیت

- `main`: نسخه‌ی پایدار
- `dev`: ادغام کارهای در حال توسعه
- `feature/...`، `fix/...`، `chore/...`، `refactor/...`: شاخه‌ی هر کار، که با Pull Request به `dev` برمی‌گردد
